Employee Data Cleaning and Analysis
A data cleaning and exploratory data analysis (EDA) project on an employee dataset, built with Python, Pandas, NumPy, Matplotlib, and Seaborn.

Overview
This project focuses on cleaning and analyzing a real-world employee dataset to extract meaningful insights. The dataset was cleaned using Pandas and NumPy, then explored through visualizations created with Matplotlib and Seaborn.

The project answers questions such as:
- What is the age distribution of employees?
- Which department regions have the highest number of employees?
- What is the distribution of employee salaries?
- How many employees are Active, Pending, or Inactive?
- How does salary compare with employee performance?

Dataset
Employee dataset, sourced from Kaggle.

Tools Used
- Python
- Pandas & NumPy — data cleaning and analysis
- Matplotlib — data visualization
- Seaborn — statistical visualization
- Jupyter Notebook

Data Cleaning
- Removed duplicate records
- Handled missing values
- Checked data types
- Converted columns to appropriate formats
- Verified dataset consistency

Key Findings
- Most employees are between 25–40 years of age.
- HR–Florida has the highest number of employees.
- Employee salaries are mainly concentrated between ₹80,000 and ₹100,000.
- Most employees fall into the Active and Pending status categories.
- Salary shows only slight variation across different performance scores.
